# 🚀 QUICK START - VAVA DOCES

## ⚡ Comece em 3 passos

### 1️⃣ Execute o Streamlit
```bash
cd /home/gilunix/Documents/Projects/Vava_doces
streamlit run app.py
```

### 2️⃣ Abra no navegador
```
http://localhost:8501
```

### 3️⃣ Explore as páginas
- **📊 Dashboard** - Métricas principais
- **💰 Custos de Produção** - Análise detalhada
- **💹 Impacto no Faturamento** - Análise financeira
- **🔍 Análise Detalhada** - Dados avançados

---

## 📊 O que você vê

### Dashboard
```
Métricas:
  🛍️ Total de Produtos: X
  💸 Custo Total: R$ X.XXX,XX
  📊 Custo Médio: R$ XXX,XX
  🔽 Custo Mínimo: R$ XX,XX

Gráfico: Custos por Produto

```

### Custos de Produção
```
Seletor: Escolha um produto
Resultado:
  ✓ Ingredientes utilizados
  ✓ Quantidades e custos
  ✓ Total de produção
```

### Impacto no Faturamento
```
Métricas:
  📈 Receita Potencial: R$ X.XXX,XX
  📊 Margem Média: XX,X%
  📦 Total de Categorias: X

Gráficos:
  • Produtos por Categoria
  • Distribuição de Margens
```
