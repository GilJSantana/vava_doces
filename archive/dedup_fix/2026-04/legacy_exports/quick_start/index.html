    🚀 QUICK START - VAVA DOCES¶

    ⚡ Comece em 3 passos¶

    1️⃣ Execute o Streamlit¶

    cd /home/gilunix/Documents/Projects/Vava_doces
streamlit run app.py

    2️⃣ Abra no navegador¶

    http://localhost:8501

    3️⃣ Explore as páginas¶

    • 📊 Dashboard - Métricas principais
    • 💰 Custos de Produção - Análise detalhada
    • 💹 Impacto no Faturamento - Análise financeira
    • 🔍 Análise Detalhada - Dados avançados
