ARCHITECTURE OVERVIEW
================================================================================
Authentication Flow:
  User Opens App
       ↓
  Is Authenticated? (OAuth2 Token)
       ├─ NO → Show Login Page → OAuth2 Flow
       │
       └─ YES → Is Authorized? (Drive Permissions)
            ├─ NO → Show Access Denied
            │
            └─ YES → Load Main Application
Components:
  1. Google OAuth2 Adapter
     - Generates login URLs
     - Exchanges codes for tokens
     - Extracts user email
  2. Drive Permission Checker
     - Validates file access
     - Checks role hierarchy
     - Returns boolean authorization
  3. Auth UI Components
     - Professional login page
     - Access denied page
     - Status indicators
  4. Session State Manager
     - Stores authentication data
     - Manages authorization status
     - Handles logout
